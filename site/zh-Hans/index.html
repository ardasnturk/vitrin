功能介绍

两件事，一个工具。

每个 App 都需要一个好的商店页面，也需要有人打理。Vitrin 两件事都能做。

制作商店页面

Claude 读取你的代码和竞争对手，然后撰写并设计商店页面所需的一切。

  • 名称、副标题、关键词、描述、新功能
  • 适配所有设备、所有语言的截图
  • App 预览、创意和 App 内活动 卡片
  • 按 App Store 规则检查后再上传

打理商店

团队的所有 App，都在一个原生窗口里。App Store Connect 能做的事，这里都能做，不用开一堆浏览器标签页。

  • 版本、构建版本、TestFlight 和评论
  • 价格、购买项目、销售和分析
  • 用户、设备、证书和 Apple Ads
  • 坐在桌前就能提交、发布或分阶段发布版本

按你的方式来用

Vitrin for Mac

原生 App。两件事都能做，无需终端。所需工具点一下就能装好。

Claude Code 插件

在仓库中输入 /vitrin。Claude 会询问你的需求，并逐一完成每个阶段。

CLI 和 Studio

每个阶段都是一条命令。vitrin studio 会在本地网页中打开同样的流程。

在路上？有了 Remote Code，Vitrin 就是 iPhone 上的原生标签页：项目、每个阶段和 App Store Connect 都在其中。

工作方式

从代码到商店，只需四步

创意工作交给 Claude，选择权在你手中。其余都是经过测试、可以阅读的命令。

  1. 1

    分析

    Vitrin 从代码中找出你的平台、语言和功能。每项功能都指向能证明它的文件，因此商店页面只会宣传 App 真正能做的事。

    自动检测 Swift、Flutter、React Native 和 Expo。

  2. 2

    调研

    在各个国家或地区搜索 App Store，用设备端 OCR 读取竞争对手的截图，并按相关性、热度和竞争度为关键词打分。

    平台和语言由你选择，绝不擅自假定。

  3. 3

    制作

    Claude 根据代码重建你的界面，无需构建，也无需模拟器。然后 Vitrin 渲染截图和视频，你可以从自己 App 的真实样例中挑选。

    需要真实截图？也可以在模拟器中构建并拍摄你的 App。

  4. 4

    检查并上传

    所有内容都在一个总览中呈现，你可以全部批准，也可以附上意见拒绝单个项目。Vitrin 只上传你批准的内容，并回读商店保存的结果。

    上传由 asc CLI 完成，无需安装 Ruby。

安全

未经你同意，任何内容都不会进入商店

Vitrin 的设计，就是为了让你放心地把线上商店页面交给它。

  • 从设计上保证真实每条标题和宣传语都必须指向代码中的功能。评分来自线上 App Store，用户好评只取自你自己的评论。
  • 抢在 Apple 之前发现一条命令按 App Store 规则检查文案、图片和视频，并明确告诉 Claude 该修什么。
  • 批准与文件绑定你的批准会记录每个文件的哈希。之后如有任何更改，即使是 Claude 改的，也需要重新批准。
  • 部分上传，就只是部分先出试运行方案。你没选择的内容绝不会被删除或覆盖，每次上传都会回读确认。

安装

一分钟上手

Vitrin for Mac

下载后拖到“应用程序”文件夹，跟随欢迎导览操作。它会检查你的 Mac，点一下就能安装缺少的工具。

下载 Mac 版

或使用 Homebrew：

brew tap ardasnturk/vitrin https://github.com/ardasnturk/vitrin brew install --cask vitrin

Claude Code 插件

安装一次后，在 Claude Code 中打开 App 的仓库，输入 /vitrin 即可。无需克隆任何内容。

claude plugin install vitrin --marketplace ardasnturk/vitrin

首次运行时会设置一次 CLI，约 450 MB（含 Chromium），无需 sudo。需要 Node.js 22 或更高版本。其余项目由 vitrin doctor 检查。

常见问题

你可能想问

支持 Flutter 或 React Native App 吗？

支持。Swift 和 SwiftUI 优先，Flutter、React Native 和 Expo 项目也会被自动检测。它们的界面可以根据代码重建而无需构建，也可以按你的偏好用各自的工具构建并在模拟器中截图。Vitrin 面向 App Store，因此只涵盖它们的 Apple 平台 App。

需要 OpenAI 或 Anthropic 的 API 密钥吗？

不需要。创意工作在你的 Claude Code 会话中完成，CLI 不调用任何 AI。不用 Claude 时，也可以按需求说明手动操作。

可以在 iPhone 上使用吗？

可以。在 Mac 上安装 Remote Code 1.6 后，Vitrin 就是 iPhone 上的一个标签页。你可以添加项目文件夹、运行每个阶段，并在原生界面中管理 App Store Connect，而且 Vitrin for Mac 无需保持打开。项目会在 iPhone 和 Mac 之间保持同步。

Mac App 需要用终端吗？

不需要。欢迎导览会检查你的 Mac，点一下就能安装 Node.js、Vitrin CLI、Claude Code、asc CLI 和 ffmpeg。有 Homebrew 时会使用它，没有也能正常工作。

不手动创建密钥，能连接 App Store Connect 吗？

可以。使用 Apple 账户登录后，Vitrin 一步创建管理员 API 密钥。你也可以自己添加密钥，或使用 asc CLI 中已有的登录信息。项目无需任何连接也能工作。

能在 App Store Connect 中创建新 App 吗？

使用 Apple 账户登录后，Vitrin for Mac 可以创建。Apple 不允许通过 API 密钥创建，所以当 App 不存在时，CLI 和插件会停下来告诉你。

会不经询问就上传内容吗？

不会。所有图片、视频和文案都会先给你看。上传从试运行方案开始，需要你的同意，与你批准的内容不一致时会被拒绝。提交审核还需要单独确认。在插件中，价格、发布、年龄分级和隐私问卷都由你亲自处理。

具体会上传什么？

只上传你批准后选定的平台和内容。选定的截图集按显示类型替换，其他内容保持不变。Vitrin 绝不上传构建版本。

需要构建我的 App 吗？

不需要。默认情况下，Claude 根据源代码用 HTML 重建你的界面，因此无需构建、模拟器或演示模式。如果你更想要真实截图，它也可以构建 App，并在专用模拟器中打开每个界面。

生成的文件会怎样？

它们保留在项目的 metadata/ 文件夹中，由受管理的 .gitignore 区块排除在 git 之外。上传并核对后，Vitrin 会询问是否删除调研数据。其他内容都不会被删除。

许可证方面呢？

Vitrin 采用 MIT 许可证。它内置 OFL 字体和 Lucide 图标，风格预设改编自 ParthJadhav/app-store-screenshots（MIT）。App 预览 使用 Remotion 渲染，个人及不超过三名员工的公司可免费使用。更大的团队需要 Remotion 公司许可证。

这是 Apple 的产品吗？

不是。Vitrin 是独立的开源项目，与 Apple Inc. 没有关联，也未获得其认可或赞助。
