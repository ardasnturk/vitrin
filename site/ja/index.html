できること

仕事はふたつ。ツールはひとつ。

どの App にも、魅力的なストアページと、それを見守る人が必要です。Vitrin はその両方を引き受けます。

ストアページをつくる

Claude があなたのコードと競合 App を読み解き、ストアページに必要なものをすべて書いて、デザインします。

  • 名前、サブタイトル、キーワード、説明、新機能
  • すべてのデバイス、すべての言語のスクリーンショット
  • Appプレビュー、クリエイティブ、Appイベント カード
  • App Store のルールに照らして確認してからアップロード

ストアを運営する

チームのすべての App を、ひとつのネイティブウインドウに。App Store Connect でできることのすべてを、ブラウザのタブなしで。

  • バージョン、ビルド、TestFlight、レビュー
  • 価格、購入、売上、分析
  • ユーザ、デバイス、証明書、Apple Ads
  • バージョンの提出もリリースも段階的リリースも、手元から

あなたの働き方に合わせて

Vitrin for Mac

ネイティブ App です。ふたつの仕事をこれひとつで。ターミナルは不要で、必要なツールもクリックひとつでインストールできます。

Claude Code プラグイン

リポジトリで /vitrin と入力してください。Claude が希望を聞きながら、すべてのステージを進めます。

CLI と Studio

すべてのステージがコマンドになっています。vitrin studio を実行すると、同じ流れをローカルの Web ページで開けます。

外出先でも使えます。Remote Code があれば、Vitrin は iPhone のネイティブタブになり、プロジェクト、すべてのステージ、App Store Connect を扱えます。

仕組み

コードからストアまで、4つのステップで

クリエイティブな作業は Claude が担当し、選ぶのはあなたです。それ以外はすべて、中身を読めるテスト済みのコマンドです。

  1. 1

    分析

    Vitrin はコードから、プラットフォーム、言語、機能を見つけ出します。機能ごとに根拠となるファイルを示すので、ストアページには App が本当にできることだけが載ります。

    Swift、Flutter、React Native、Expo を自動で検出します。

  2. 2

    調査

    国ごとに App Store を検索し、競合のスクリーンショットをデバイス上の OCR で読み取り、関連性、人気、競争の激しさからキーワードを評価します。

    プラットフォームと言語はあなたが選びます。勝手に決めることはありません。

  3. 3

    作成

    Claude がコードから画面を再現します。ビルドもシミュレータも不要です。そのあと Vitrin がスクリーンショットとビデオをレンダリングするので、あなたの App の実際のサンプルを見ながら選べます。

    実際の画面キャプチャが必要なら、シミュレータで App をビルドして撮影することもできます。

  4. 4

    確認してアップロード

    すべてをひとつのギャラリーで確認して承認できます。コメントを添えて1点だけ却下することも可能です。Vitrin は承認した内容だけをアップロードし、ストアに保存された内容を読み戻して確認します。

    アップロードは asc CLI が行うので、Ruby のインストールは不要です。

安全性

あなたの「はい」がなければ、何もストアに届きません

Vitrin は、公開中のストアページを安心して任せられるように作られています。

  • 設計から正直に見出しや主張は、すべてコード内の機能に紐づいている必要があります。評価は公開中の App Store から、お客様の声はあなた自身のレビューからのみ引用します。
  • Apple より先に発見ひとつのコマンドで、テキスト、画像、ビデオを App Store のルールに照らして確認し、直すべき点を Claude に正確に伝えます。
  • 承認はファイルに紐づく承認時に、すべてのファイルのハッシュを記録します。その後に変更があれば、たとえ Claude による変更でも、再度承認が必要です。
  • 部分アップロードは、部分のまままずドライランの計画を確認します。選ばなかったものが削除や上書きされることはなく、アップロードした内容はすべて読み戻して確認します。

細かなところまで

ほかにも、うれしい機能をひと通り

Vitrin Studio

すべての流れをローカルの Web ページで。ライブログ、エディタ、デザインサンプル、確認用ギャラリー、そしてサイドパネルにはあなたの Claude Code。

追加の AI キーは不要

クリエイティブな作業は、あなた自身の Claude Code セッションで実行されます。CLI 自体は AI を呼び出しません。

途中から再開

変更のないステージはスキップします。キーがなくても作業は止まらず、待つのはアップロードだけです。

すっきりしたリポジトリ

すべてはひとつの metadata/ フォルダにまとまり、git には含まれません。キーは .env に保管され、どのログでもマスクされます。

カスタムプロダクトページ

カスタムプロダクトページ、Appイベント、Appアセットライブラリもストアページと一緒にアップロードできます。

ストアのルールを内蔵

文字数制限、キーワードのルール、App審査のポリシーを、結果をお見せする前に言語ごとに確認します。

よくある質問

気になること、お答えします

Flutter や React Native の App でも使えますか？

はい。Swift と SwiftUI を中心にしつつ、Flutter、React Native、Expo のプロジェクトも自動で検出します。画面はビルドせずにコードから再現できるほか、希望があればそれぞれのツールでビルドしてシミュレータでキャプチャすることもできます。Vitrin は App Store 向けのツールなので、対象は Apple プラットフォーム向けの App のみです。

OpenAI や Anthropic の API キーは必要ですか？

いいえ。クリエイティブな作業はあなたの Claude Code セッション内で行われ、CLI は AI を呼び出しません。Claude を使わずに、ブリーフに沿って手作業で進めることもできます。

iPhone から使えますか？

はい。Mac に Remote Code 1.6 があれば、Vitrin は iPhone のタブになります。プロジェクトフォルダの追加、すべてのステージの実行、App Store Connect の管理をネイティブ画面で行え、Vitrin for Mac を開いておく必要もありません。プロジェクトは iPhone と Mac の間で同期されます。

Mac App にターミナルは必要ですか？

いいえ。ウェルカムツアーが Mac をチェックし、Node.js、Vitrin CLI、Claude Code、asc CLI、ffmpeg をクリックひとつでインストールします。Homebrew があれば利用しますが、なくても動作します。

キーを手動で作成せずに App Store Connect に接続できますか？

はい。Apple アカウントでサインインすれば、Vitrin が管理者 API キーを1ステップで作成します。自分でキーを追加したり、asc CLI のログインをそのまま使ったりすることもできます。プロジェクトは接続しなくても動作します。

App Store Connect で新しい App を作成できますか？

Apple アカウントでサインインすれば、Vitrin for Mac で作成できます。API キーでの作成は Apple が許可していないため、CLI とプラグインは App が見つからない場合に停止してお知らせします。

確認なしに何かをアップロードすることはありますか？

いいえ。すべての画像、ビデオ、テキストは最初にお見せします。アップロードはドライランの計画から始まり、あなたの「はい」が必要で、承認した内容と異なるものは拒否します。審査への提出には別途確認が必要です。プラグインでは、価格、リリース、年齢制限とプライバシーの質問票はあなたにお任せします。

具体的に何がアップロードされますか？

承認後に、選択したプラットフォームと内容だけがアップロードされます。選択したスクリーンショットセットはディスプレイの種類ごとに置き換えられ、それ以外はそのまま残ります。Vitrin がビルドをアップロードすることはありません。

App をビルドする必要はありますか？

いいえ。標準では Claude がソースコードから HTML で画面を再現するので、ビルドもシミュレータもデモモードも必要ありません。実際のキャプチャがよければ、App をビルドして専用のシミュレータで各画面を開くこともできます。

生成されたファイルはどうなりますか？

プロジェクトの metadata/ フォルダに保存され、管理された .gitignore ブロックによって git から除外されます。アップロードの確認が済むと、Vitrin は調査データを削除するか尋ねます。それ以外は何も削除されません。

ライセンスについて教えてください。

Vitrin は MIT ライセンスです。OFL フォントと Lucide アイコンを同梱しており、スタイルプリセットは ParthJadhav/app-store-screenshots（MIT）をもとにしています。Appプレビュー のレンダリングには Remotion を使用しており、個人および従業員3人までの企業は無料で利用できます。それより大きなチームには Remotion のカンパニーライセンスが必要です。

これは Apple の製品ですか？

いいえ。Vitrin は独立したオープンソースプロジェクトで、Apple Inc. との提携関係はなく、Apple Inc. による承認や支援も受けていません。
