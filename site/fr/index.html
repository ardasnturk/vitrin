Ce que fait Vitrin

Deux métiers. Un seul outil.

Chaque app a besoin d’une belle page sur le store et de quelqu’un pour s’en occuper. Vitrin fait les deux.

Créer la fiche

Claude lit votre code et vos concurrents, puis écrit et conçoit tout ce qu’il faut pour votre page sur le store.

  • Nom, sous-titre, mots-clés, description, Nouveautés
  • Des captures d’écran pour chaque appareil, dans chaque langue
  • App Previews, visuels et cartes In-App Event
  • Vérifié selon les règles de l’App Store, puis envoyé

Gérer le store

Toutes les apps de votre équipe dans une seule fenêtre native. Tout ce que fait App Store Connect, sans les onglets du navigateur.

  • Versions, builds, TestFlight et avis
  • Prix, achats, ventes et analyses
  • Utilisateurs, appareils, certificats et Apple Ads
  • Soumettez, publiez ou déployez progressivement une version depuis votre bureau

Comme vous aimez travailler

Vitrin pour Mac

L’app native. Les deux métiers, sans terminal. Elle installe en un clic les outils qu’il lui faut.

Plug-in Claude Code

Tapez /vitrin dans votre dépôt. Claude vous demande ce que vous voulez et avance étape par étape.

CLI et Studio

Chaque étape est une commande. vitrin studio ouvre le même parcours dans une page web locale.

En déplacement ? Avec Remote Code, Vitrin devient un onglet natif sur votre iPhone : projets, toutes les étapes et App Store Connect.

Comment ça marche

De votre code au store en quatre étapes

Claude s’occupe de la création, vous faites les choix. Tout le reste, ce sont des commandes testées que vous pouvez lire.

  1. 1

    Analyser

    Vitrin repère vos plateformes, vos langues et vos fonctionnalités dans le code. Chaque fonctionnalité renvoie au fichier qui la prouve : votre fiche n’affirme donc que ce que votre app fait vraiment.

    Swift, Flutter, React Native et Expo, détectés automatiquement.

  2. 2

    Recherche

    Il explore l’App Store de chaque pays, lit les captures d’écran des concurrents grâce à l’OCR sur l’appareil et note les mots-clés selon leur pertinence, leur popularité et la concurrence.

    Vous choisissez les plateformes et les langues. Rien n’est décidé à votre place.

  3. 3

    Créer

    Claude recrée vos écrans à partir du code, sans build ni simulateur. Vitrin génère ensuite les captures d’écran et les vidéos, et vous choisissez parmi de vrais exemples de votre propre app.

    Besoin de vraies captures ? Il peut aussi compiler votre app et la photographier dans des simulateurs.

  4. 4

    Vérifier et envoyer

    Vous voyez tout dans une seule galerie et vous approuvez, ou vous rejetez un seul élément avec un commentaire. Vitrin envoie exactement ce que vous avez approuvé et relit ce que le store a enregistré.

    C’est la CLI asc qui fait l’envoi, il n’y a donc pas de Ruby à installer.

Sécurité

Rien n’arrive sur le store sans votre accord

Vitrin est conçu pour qu’on lui confie une fiche déjà en ligne.

  • Honnête par conceptionChaque titre et chaque affirmation doivent renvoyer à une fonctionnalité de votre code. Les notes viennent de l’App Store en direct, et les témoignages uniquement de vos propres avis.
  • Repéré avant AppleUne seule commande vérifie les textes, les images et les vidéos selon les règles de l’App Store, et dit à Claude exactement quoi corriger.
  • Une approbation liée aux fichiersVotre approbation enregistre un hash de chaque fichier. Si quelque chose change ensuite, même par Claude, il faut une nouvelle approbation.
  • Un envoi partiel reste partielD’abord un plan de simulation. Ce que vous n’avez pas sélectionné n’est jamais supprimé ni écrasé, et chaque envoi est relu.

Et les détails

Tout ce qu’il vous faut en plus

Vitrin Studio

Tout le parcours dans une page web locale : journaux en direct, éditeurs, exemples de design, galerie de revue et votre propre Claude Code dans un panneau latéral.

Aucune clé d’IA en plus

Le travail créatif se fait dans votre propre session Claude Code. La CLI elle-même n’appelle aucune IA.

Reprend là où il s’est arrêté

Les étapes sautent ce qui n’a pas changé. Des clés manquantes n’arrêtent pas le travail : seul l’envoi les attend.

Un dépôt bien rangé

Tout tient dans un seul dossier metadata/, tenu à l’écart de git. Les clés restent dans .env et sont masquées dans tous les journaux.

Custom Product Pages

Envoyez les Custom Product Pages, les In-App Events et la bibliothèque de ressources de l’app en même temps que votre fiche.

Les règles du store intégrées

Limites de caractères, règles des mots-clés et politiques de l’App Review sont vérifiées dans chaque langue avant que vous ne voyiez le résultat.

Installer

Démarrez en une minute

Vitrin pour Mac

Téléchargez, glissez dans Applications et suivez la visite de bienvenue. Elle vérifie votre Mac et installe en un clic ce qui manque.

Télécharger pour Mac

Ou avec Homebrew :

brew tap ardasnturk/vitrin https://github.com/ardasnturk/vitrin brew install --cask vitrin

Plug-in Claude Code

Installez-le une fois, ouvrez le dépôt de votre app dans Claude Code et tapez /vitrin. Rien à cloner.

claude plugin install vitrin --marketplace ardasnturk/vitrin

Le premier lancement installe la CLI une seule fois : environ 450 Mo avec Chromium, sans sudo. Il vous faut Node.js 22 ou ultérieur. vitrin doctor vérifie le reste.

FAQ

Bonnes questions

Ça marche avec les apps Flutter ou React Native ?

Oui. Swift et SwiftUI passent en premier, et les projets Flutter, React Native et Expo sont détectés automatiquement. Leurs écrans sont recréés à partir du code sans build, ou compilés avec leurs propres outils et capturés dans des simulateurs si vous préférez. Vitrin est fait pour l’App Store : seules leurs apps Apple sont couvertes.

Faut-il une clé API OpenAI ou Anthropic ?

Non. Le travail créatif se fait dans votre session Claude Code, et la CLI n’appelle aucune IA. Sans Claude, vous pouvez suivre les briefs à la main.

Puis-je l’utiliser depuis mon iPhone ?

Oui. Avec Remote Code 1.6 sur votre Mac, Vitrin devient un onglet sur votre iPhone. Vous pouvez ajouter des dossiers de projet, lancer chaque étape et gérer App Store Connect dans des écrans natifs, sans que Vitrin pour Mac soit ouvert. Les projets restent synchronisés entre le téléphone et le Mac.

Faut-il le terminal pour l’app Mac ?

Non. La visite de bienvenue vérifie votre Mac et installe en un clic Node.js, la CLI Vitrin, Claude Code, la CLI asc et ffmpeg. Elle utilise Homebrew si vous l’avez et fonctionne très bien sans.

Puis-je connecter App Store Connect sans créer de clé à la main ?

Oui. Connectez-vous avec votre compte Apple et Vitrin crée une clé API administrateur en une étape. Vous pouvez aussi ajouter une clé vous-même ou utiliser la connexion déjà présente dans la CLI asc. Les projets fonctionnent sans aucune connexion.

Peut-il créer une nouvelle app dans App Store Connect ?

Vitrin pour Mac le peut, une fois connecté avec votre compte Apple. Apple ne le permet pas avec une clé API : la CLI et le plug-in s’arrêtent donc et vous préviennent quand l’app n’existe pas.

Envoie-t-il quoi que ce soit sans demander ?

Non. Chaque image, vidéo et texte vous est montré d’abord. L’envoi commence par un plan de simulation, attend votre accord et refuse tout contenu différent de ce que vous avez approuvé. La soumission pour revue demande sa propre confirmation. Dans le plug-in, les prix, les publications et les questionnaires de classification par âge et de confidentialité restent entre vos mains.

Qu’est-ce qui est envoyé exactement ?

Seulement les plateformes et le contenu que vous avez sélectionnés, après votre approbation. Les jeux de captures d’écran sélectionnés sont remplacés par type d’écran, et tout le reste ne bouge pas. Vitrin n’envoie jamais de build.

Doit-il compiler mon app ?

Non. Par défaut, Claude recrée vos écrans en HTML à partir du code source : pas de build, pas de simulateur, pas de mode démo. Si vous préférez de vraies captures, il peut compiler votre app et ouvrir chaque écran dans des simulateurs dédiés.

Que deviennent les fichiers générés ?

Ils restent dans le dossier metadata/ de votre projet, et un bloc .gitignore géré les garde hors de git. Après un envoi vérifié, Vitrin demande s’il doit supprimer les données de recherche. Rien d’autre n’est supprimé.

Et les licences ?

Vitrin est sous licence MIT. Il embarque des polices OFL et des icônes Lucide, et les styles prédéfinis sont adaptés de ParthJadhav/app-store-screenshots (MIT). Les App Previews sont générées avec Remotion, gratuit pour les particuliers et les entreprises de trois employés au plus. Les équipes plus grandes ont besoin d’une licence entreprise Remotion.

Est-ce un produit Apple ?

Non. Vitrin est un projet open source indépendant, sans lien avec Apple Inc., qui ne l’approuve ni ne le parraine.
