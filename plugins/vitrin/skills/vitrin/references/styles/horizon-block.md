# Horizon Block (`horizon-block`)

> Vitrin's own preset, distilled from fitness and utility galleries that stand the phone in a solid color block. No app's screenshots or assets were copied.

White above, one solid block of color below, and the phone standing across the line. Tall condensed caps with one word in the block's color. The most legible preset at search-result size.

```json
{ "preset": "horizon-block", "brand": { "primary": "#…" } }
```

## Palette (as rendered)

| Token | Value |
|---|---|
| Top | `#FFFFFF`, ink `#0D1220` |
| Block | `#2F5BFF` (replaced by the brand when it clears the contrast pairs) |
| Inverted slide | `#0D1220` with the same block |

## Typography

Barlow Condensed 800, uppercase, ~0.158 × width, up to three lines, centered. Body Inter.

## Use it when

Trackers, gyms, sports, utilities: clear verbs ("Log", "Plan", "Track"). Pairs well with `captionPlate`: the block and the plate share a color.
