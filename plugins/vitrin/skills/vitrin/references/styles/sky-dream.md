# Sky Dream (`sky-dream`)

> Vitrin's own preset, distilled from store galleries that set the phone in an open sky. No app's screenshots or assets were copied.

A deep blue sky falling to pale light, a bank of soft clouds low on the canvas, and a few clouds drifting in front of the device's foot so the phone seems to stand in them. Centered white type with one warm word. The inverted slide is dusk: violet to peach.

```json
{ "preset": "sky-dream" }
```

## Palette (as rendered)

| Token | Value |
|---|---|
| Day | `#1259C3` → `#1F6FE0` → `#BFE0FF`, white type, emphasis `#FFF0A8` |
| Dusk (`inverted`) | `#3B2A8C` → `#8E3F91` → `#FFB27A`, emphasis `#FFD9A0` |

The sky is fixed (`tint: fixed`): a brand color would stop it reading as sky. Use another preset when the brand has to lead.

## Typography

Plus Jakarta Sans 800, ~0.122 × width, centered.

## Use it when

Travel, money and aspiration: "the new way to…", earning, escaping, planning a trip. `thread: "dashed"` reads as a flight path. One dusk slide per set is enough.
