# Ink Minimal (`ink-minimal`)

> Vitrin's own preset, distilled from the white, almost empty galleries of calm notes, journal and AI apps. No app's screenshots or assets were copied.

White canvas, near-black ink, a flush-left headline with one word marked as if by a highlighter, and a thin hand-drawn arrow from the caption to the phone on every other slide. Nothing else: the UI is the only color.

```json
{ "preset": "ink-minimal", "brand": { "primary": "#…" } }
```

## Palette (as rendered)

| Token | Value |
|---|---|
| Paper | `#FFFFFF`, ink `#0E0E10` |
| Marker | `#FFD84D` (replaced by the brand when it reads as a marker) |
| Inverted slide | ink `#0E0E10` with white type |

## Typography

Inter Tight 600, ~0.118 × width, leading 1.04, flush left. Body Inter 400.

## Use it when

The app's UI is already colorful or the category is loud. It stands out most next to saturated competitors. Keep copy to one short line per slide; a subheadline is rarely needed. `thread: "line"` suits it well.
